PeerPar Verify

Re-hash a file in your browser and check it against an on-chain proof anchor. The file never leaves your device.

⚠️ Before you interpret this result

✅ A MATCH proves:
  • ✅ This exact file was anchored on-chain
  • ✅ At approximately the recorded time
  • ✅ By the recorded device address
❌ A MATCH does NOT prove:
  • ❌ The content is real or unedited
  • ❌ The file origin or context
  • ❌ Anything before capture began
"This record proves that the file shown existed in exactly this form at approximately the time shown. It does not prove that the content is genuine, unedited prior to capture, or that it accurately depicts real events."
